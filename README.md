# CarwashIApp

Sistema de gestión integral para autolavados. Órdenes, clientes, finanzas y más.

## Tecnologías

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS

## Empezar el proyecto

1. Instalar dependencias:
```sh
npm install
```

2. Configurar base de datos:
Asegúrate de agregar las variables de entorno de Supabase en `.env` (guíate por `.env.example`).

3. Ejecutar en desarrollo:
```sh
npm run dev
```
